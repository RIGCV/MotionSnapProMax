# 目录选择与本地保存修复验收（2026-11-18）

## 检查范围与结论

检查网页入口、目录辅助模块、PNG 编码、写入模块、Worker、模型配置、移动检测、跟踪、事件绑定、页面 DOM、部署脚本和现有测试。Python 桌面端与本次网页问题无关，未改动。

确认的代码问题：

- 上一版 picker 使用 `mode: read`，随后跨异步边界申请写入，与要求的直接 readwrite 选择流程不同，增加权限交互的不确定性。已改为点击内直接调用 readwrite picker，返回后只验证；补充授权仅由明确的授权按钮发起。
- 手动截图未经过自动截图的互斥锁。现两者共享同一锁，编码与写入均最多一个任务在途。
- 写入失败未可靠地撤销本地可写标记。现失败暂停自动保存、清除标记并保留错误，检测循环绝不申请权限。
- 停止与未结束写入的生命周期未统一。现停止立即关闭媒体轨道，编码中的旧帧不写入，已经开始的写入完成后计数；在途任务结束前不允许重启/换目录。
- 旧版 AbortError 提示曾误判取消。现只报告选择/授权未完成，记录原始异常及阶段，不将名称视为唯一原因。

未发现的疑因：按钮各绑定一次，没有重复监听器；picker 调用前没有 await、模型初始化、摄像头请求或定时器；并发选择锁已有并经回归测试；句柄保存在模块状态，不是易丢失的局部变量。旧代码中的这些部分不能作为用户 Edge 故障的已确认原因。

**尚不能确认用户机器上原生 AbortError 的底层唯一原因。** 文件夹普通、磁盘健康不能证明浏览器已授予权限。必须结合真实 Edge 的目录选择日志与授权结果继续定位，不能仅凭模拟测试宣布原生问题已解决。
